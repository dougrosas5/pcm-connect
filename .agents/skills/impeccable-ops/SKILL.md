# Impeccable — revisión adaptada a PCM Connect

Referencias originales del proyecto Impeccable compartidas por el usuario: `references/original-impeccable.md`, `operate.md`, `audit.md`, `polish.md`, `craft-floor.md`.

- Usar **Operate**: que la persona complete la tarea es más importante que animaciones e impacto publicitario.
- El brief Graphite y la lógica del producto tienen prioridad; no modificar datos ni flujos para mejorar estética.
- Antes de editar: analizar pantalla, estados, densidad de información, foco y contraste.
- Leer `references/craft-floor.md` antes de modificar UI y `references/operate.md` para interfaces operativas.
- Realizar auditoría de accesibilidad/errores con `references/audit.md`, corregir lotes concretos y validar una vez más.
- Evitar sobreingeniería, scripts ejecutables externos, hooks automáticos y descargas sin autorización.
- Hacer cambios acotados que mantengan layout y comportamiento conocido; explicar claramente diferencias.

Esta es una adaptación de instrucciones, NO instala el lanzador de Impeccable. El usuario puede pedir instalar el original luego de evaluar scripts/dependencias.

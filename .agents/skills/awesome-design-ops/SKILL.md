# Awesome Design MD — adaptación para PCM Connect

Esta skill se basa en las guías `DESIGN.md` del archivo awesome-design-md compartido por el usuario. No es una plantilla visual ni debe sobrescribir `docs/DISEÑO_GRAPHITE.md`.

1. Leer el requerimiento funcional y los tokens Graphite.
2. Examinar selectivamente `references/linear.md` para jerarquías operativas; `references/airtable.md` para tablas densas y estados; `references/figma.md` para inspector y paneles de edición.
3. Extraer principios genéricos (jerarquía, consistencia, interacción) sin adoptar los colores/branding/estructura exacta de ninguna referencia.
4. Para cada UI, priorizar casos reales: una OM por fila, filtros, errores, asignación y señales de conflicto.
5. Verificar accesibilidad, legibilidad y consistencia después de editar.

No usar imágenes externas ni copiar recursos de terceros sin necesidad.
